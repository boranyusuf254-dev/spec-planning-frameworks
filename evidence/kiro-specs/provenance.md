## Availability check

`kiro-cli` was not installed. The official stable manifest at `https://prod.download.cli.kiro.dev/stable/latest/manifest.json` reported version `2.13.0`. The official installer targets system application locations, and running the workflow requires Kiro browser authentication. This comparison had neither a Kiro account grant nor permission to install outside the repository, so no vendor CLI command was executed.

Kiro's current documentation describes a three-file flow—requirements, design, and implementation tasks—started with `/spec new` in the current CLI experience. We wrote an original example that follows that documented file model and uses EARS-style acceptance criteria. Every file is labeled **manual, source-faithful example — not generated by Kiro**.
